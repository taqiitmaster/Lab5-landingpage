## 4. Design Direction and Visual Identity

Create a futuristic, premium, minimalist, and sophisticated design.

The website should combine the visual quality of a high-end software engineer portfolio with the polished presentation of a modern technology company.

### Recommended visual theme

- Background: deep charcoal or near-black, such as #0A0A0F.
- Primary accent: electric violet or sophisticated purple, such as #8B5CF6.
- Secondary accent: subtle cyan, such as #22D3EE.
- Main text: white or soft white.
- Secondary text: muted grey.
- Borders: subtle, low-contrast lines.
- Cards: dark surfaces with restrained transparency and soft highlights.

Keep the color palette consistent. Do not use too many colors, excessive gradients, bright neon everywhere, or cheap-looking glow effects.

Use premium typography such as Inter, Manrope, or Space Grotesk. Create a strong typographic hierarchy with large headings, readable body text, generous spacing, and carefully balanced proportions.

### Visual effects

Use selected effects to create a premium futuristic atmosphere:

- Subtle animated background elements.
- A restrained purple or cyan ambient glow.
- Soft glassmorphism only where appropriate.
- Fine grid patterns or understated technical details.
- Smooth scrolling.
- Elegant hover states.
- Subtle card depth and borders.
- Small animated indicators and status elements.
- Smooth section reveal animations.
- Sophisticated transitions between interactive elements.

Animations must feel intentional and professional. Avoid excessive particles, constant movement, distracting 3D effects, or animations that make the website feel like a gaming interface.

The website must remain fast, readable, and accessible.
